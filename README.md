
# Age Checker

## Description

Age Checker is a web application that checks the user's age and displays whether they are underage or of legal age.

## Objective

Practice JavaScript events and DOM manipulation by creating an interactive age verification system.

## Features

- Accepts the user's age through a numeric input.
- Identifies users under 18 years old.
- Identifies users aged 18 or older.
- Displays different messages and colors according to the result.
- Validates invalid and negative values.
- Clears the result when the input is empty.

## Technologies

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download the project files.
2. Keep all files in the same folder.
3. Open `index.html` in a web browser.
4. Enter an age in the input field.
5. Check the displayed result.
